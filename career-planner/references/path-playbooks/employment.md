# 就业方向 Playbook（面向应届 / 校招）

## 输入信息

从 `profile.yaml` 获取：`education.major`、`experiences`、`skills.hard`、`assessment.holland`、`goals.targets`。

## 匹配步骤

1. **岗位候选生成**：结合 Holland Code 与专业 + 已有实习/项目，产出 3-6 个候选岗位（行业 × 职能）。
2. **能力差距分析**：对每个候选岗位列 5-8 项核心能力，标记"已具备/初步/待补齐"。
3. **信息渠道**：给出该岗位典型 JD 关键词，用户可以拿去搜岗位，也可以喂给 `resume-optimizer`。
4. **路径决策**：给出 A/B/C 三档（保底 / 主攻 / 冲刺）目标。

## 校招时间线（内地）

| 阶段 | 时间 | 关键动作 |
|---|---|---|
| 提前批 / 内推 | 毕业前 1 年的 3-5 月 | 大厂春招内推、暑期实习申请（**转正机会**） |
| 暑期实习 | 6-8 月 | 用一段完整实习换转正 offer / 履历 |
| 秋招（正式） | 毕业前 1 年的 8-11 月 | 主战场，投递 30-60 家 |
| 秋招补招 | 12 月 - 次年 2 月 | 岗位少但仍有机会 |
| 春招 | 次年 3-5 月 | 补录、日常岗，机会明显少于秋招 |

**给应届生的核心建议**：暑期实习尽量拿一段"能转正的大厂/头部公司"，秋招的谈判筹码 80% 来自此段实习。

## 常见职能岗位画像（简版）

### 后端 / 服务端工程师
- 核心能力：一门系统语言（Go/Java/Rust/C++）+ 一门脚本语言、数据库、分布式基础、算法
- 差异化：开源贡献、系统设计能力、性能优化案例

### 前端 / 全栈
- 核心能力：JS/TS 深度、一款主流框架、工程化、浏览器原理、可访问性
- 差异化：编辑器/低代码/开发者工具方向的深度项目

### 数据 / 算法
- 核心能力：Python 数据栈、SQL、统计基础、一个方向的领域知识（NLP/CV/推荐）
- 差异化：Kaggle 名次 / 论文一作 / 竞赛奖项

### 产品经理
- 核心能力：需求分析、结构化表达、数据敏感度
- 差异化：自己做过一个上线的小产品（含用户/数据）

## 输出

给用户一份「岗位候选表 + 能力差距 + 3-6-12 月里程碑 + 关键节点日历」，落地到 `career_plan.md`。
