# 考公 / 事业单位 Playbook

## 路径分支

| 路径 | 说明 | 主要考试 |
|---|---|---|
| 国考 | 中央国家机关 | 行测 + 申论（+专业科目） |
| 省考 | 各省公务员 | 行测 + 申论（时间通常错开国考） |
| 选调生 | 面向高校毕业生的定向招录 | 类似省考 + 面试 |
| 事业单位 | 学校、医院、科研院所行政岗 | 公基 / 行测 + 专业课 |
| 参公 / 遴选 | 已工作后转公务员 | 行测 + 面试 |

## 关键节点（应届 / 参考）

| 时间 | 动作 |
|---|---|
| 大三下 | 决定是否参加，评估性格 / 家庭 / 城市匹配度 |
| 大四上 6-7 月 | 选调生开始报名（部分省份） |
| 大四上 10 月 | 国考公告发布 |
| 大四上 11-12 月 | 国考笔试 |
| 大四下 2-4 月 | 面试、体检、政审 |
| 大四下 3-5 月 | 各省省考陆续 |

## 岗位选择考量

- **岗位匹配度**：专业限制、政治面貌、性别倾向、基层服务年限
- **地点**：一线城市 vs 家乡；乡镇岗位竞争小但需要长期扎根
- **发展路径**：中央 / 省直 / 市直 / 区县 / 乡镇 → 不同天花板与晋升节奏
- **稳定 vs 事业心**：Holland Code 含 C（常规型）+ S（社会型）通常契合度高；含 A（艺术型）为主的通常需要慎重

## 备考核心

- **行测**：题量大、时间紧，靠刷题量堆速度和准确率（近 10 年真题反复刷）
- **申论**：靠输入 + 输出，背材料 + 每周至少一篇完整卷
- **面试**：结构化面试为主，8-15 分钟 3-4 题，考察表达 / 综合分析 / 情境应对

**给应届生的建议**：如果 Holland Code 里 C < 30 分，认真考虑是否真的适合，而不是"没别的选项才考"。
