# Demo Assets

将演示 GIF 放在此目录下：

- `career-planner-demo.gif` — 职业规划完整对话流程演示
- `resume-builder-demo.gif` — 简历生成与主题切换演示
- `overview.gif` — 整体功能快速概览（推荐 README 首图）

## 录制建议

- 工具：macOS 用 CleanShot X 或 Gifox，跨平台用 LICEcap
- 分辨率：宽度 800px，保持清晰且文件不过大
- 时长：每个 GIF 控制在 30s 以内
- 内容要点：
  - career-planner: 展示从"我该考研还是工作"到生成 career_plan.md 的完整流程
  - resume-builder: 展示对话式填写信息 → 选主题 → 渲染 HTML 预览的过程
