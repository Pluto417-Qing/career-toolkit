三步完成简历

从聊天到 PDF，全程自动化

1

对话收集

AI 按「基础信息 → 教育 → 经历 → 技能」节奏提问，你只需自然回答。

2

校验渲染

自动进行 Schema 校验，选择主题后渲染为排版精美的 HTML 页面。

3

导出分享

输出 PDF / JSON / Markdown，可直接发飞书或投递到招聘平台。

快速开始

在 IDE 中直接使用

Terminal
# 1. 克隆项目
$ git clone https://github.com/Pluto417-Qing/resume-skill.git

# 2. 安装依赖
$ pip install PyYAML Jinja2 jsonschema

# 3. 在编辑器中打开，开始对话
# 直接告诉 AI："帮我生成一份简历"
# AI 会自动读取 Skill 配置并引导你完成
