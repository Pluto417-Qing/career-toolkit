# 简历写作建议

面向**清华大学本科生**的最短版指南。核心：**具体、量化、动词开头、真实**。

## Bullet 三要素：动作 + 结果 + 度量

不推荐：
> - 参与了 XX 系统的开发，负责前端相关工作，学习了很多东西

推荐：
> - **主导** XX 表单引擎重构，将 30+ 场景 schema 化，前端代码行数 **下降 45%**
> - **引入** 运行时校验框架，将线上表单类问题 **减少 60%**

模板：
```
[动词开头] [做了什么] [涉及范围/规模] [造成的量化结果]
```

**动词库**：主导 / 独立完成 / 设计 / 落地 / 推动 / 优化 / 沉淀 / 复现 / 分析 / 支持

## 清华学生特有经历怎么写

### SRT / 国创
- 写明课题名、导师实验室、具体工作、产出（论文/专利/系统）
- 量化：实验提升百分比、数据集规模、模型对比基线
- 示例：`在XX实验室参与SRT项目「基于图神经网络的推荐系统」，负责特征工程，对比基线提升Recall@10 8.3%`

### 挑战杯
- 写明届数、赛道、作品名、奖项等级、个人角色
- 示例：`组队参加第38届挑战杯，作品「基于大语言模型的代码审计系统」获一等奖，负责前端可视化`

### 实验室科研
- 写明实验室名、导师（可选）、研究方向、具体贡献
- 有论文的一定写清楚会议/期刊名和作者排序
- 示例：`在自然语言处理实验室参与大模型对齐研究，产出1篇ACL工作坊论文（第二作者）`

### 大厂实习
- 清华学生实习多在大二大三暑假，突出是否有 return offer
- 算法岗写模型在业务中的实际效果（不是离线指标）
- 开发岗写系统影响面（QPS/用户数/线上效果）
- 示例：`在字节跳动商业化技术部门担任前端开发实习生，主导广告投放系统重构，获 return offer`

### 竞赛
- ACM 写明具体赛事名和排名（不是只写"金奖"）
- 数学建模写明角色（建模/编程/写作）
- 示例：`校ACM集训队队员，第47届ICPC亚洲区域赛金奖（队伍排名12）`

## 奖学金写作规范

- 首次出现写全称，不用缩写（如"国家奖学金"不用"国奖"）
- 按级别排序：国家级 > 校级特等 > 校级一等 > 校级二等 > 院系级
- 连续多年获奖写"连续3年获XX奖学金"
- 详见 [scholarships.yaml](../assets/tsinghua/scholarships.yaml)

## 没有数字怎么办

优先找这几类量化：
- 规模：条数、场景数、用户数、代码行数
- 时间：从 X 小时缩短到 Y 分钟
- 质量：bug 数下降、覆盖率提升、可用性 SLO
- 对外影响：文档阅读量、star 数、复用团队数

真的没有时，用相对量化（"占团队核心模块 3/8"）或直接说事实（"作为 Owner 沉淀了 4 篇技术方案"），比空口"很好地完成"更可信。

## 简历字段的取舍

- **不要**：政治面貌、身高体重、婚姻状况、身份证号、家庭地址、家庭成员详情
- **可以有**：城市偏好、性别（可选）、期望岗位（放在 `basics.label`）
- **加分**：GitHub / 技术博客 / 作品集链接（放到 `basics.profiles`）
- **清华学生特色**：
  - GPA（≥3.5/4.0 或 85+/100 建议写）
  - 排名（前 20% 建议写，前 10% 必写）
  - 核心课程（≤6 门，选与求职方向相关的）
  - 邮箱可用 `xxx@stu.tsinghua.edu.cn`

## JD 关键词融入原则

当根据 JD 优化简历时，关键词融入必须自然：
- **每个 bullet 最多融入 1 个新关键词**，避免堆砌感
- 融入后的句子必须语义通顺，不能生硬插入
- 优先融入已有相关技术的经历段
- 如果简历确实没有相关经历，**不要虚构**，建议用 evidence_gap 的改写建议先确认

## 长度控制

- 应届/新人：**1 页**为宜，字号不小于 10pt
- 有 3+ 段工作经历：可 2 页，但同一段经历不要跨页
- 每段经历的 `highlights` 建议 **3-5 条**，超过 6 条会显得冗长

## 顺序建议

一般：**基础 → 教育 → 实习/工作 → 项目 → 技能 → 获奖 → 其他**

若你的强项是项目而非公司背景（如独立开发者、开源作者），把 `projects` 提到 `work` 之前。可以通过在 `resume.yaml` 里字段顺序 + 自定义主题实现。

## 中英双语

短期最简单方式：**同一份 yaml，`language: zh`；如需英文版单独维护 `resume-en.yaml`**。避免在同一份文件里塞中英对照，模板复杂度会飙升。
