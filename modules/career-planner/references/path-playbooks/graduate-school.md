# 读研 Playbook（考研 / 保研 / 留学）

先判断分支：**保研 / 考研 / 留学 / 直博**，四条路径的时间线和准备重点差异极大。

## 路径速判

| 路径 | 触发条件 | 决策时间 |
|---|---|---|
| 保研 | 本科前 6 学期综合排名靠前（一般前 10-30%，看学校政策） | 大二结束前决定 |
| 直博 | 有明确研究方向 + 导师推荐 | 大三上确认 |
| 考研 | 保研无望或目标院校不接收外校保研 | 大三上开始 |
| 留学 | 家庭支持 + 语言基础 + 想跨地区/跨学科 | 大二结束前启动 |

## 保研（推免）

### 关键节点

| 时间 | 动作 |
|---|---|
| 大一 - 大三 | 保 GPA / 排名；至少 1 段科研 / 竞赛 |
| 大三下（3-5 月） | 联系目标院校夏令营（4-5 月投递） |
| 大三暑假（6-7 月） | 参加夏令营（拿到"优秀营员"= 半个 offer） |
| 大四上（9 月） | 预推免 / 九推 |
| 大四上（10 月） | 教育部系统填报，确认 offer |

### 准备清单

- **硬指标**：加权成绩、专业排名、六级/雅思、发表/竞赛
- **软材料**：个人陈述、简历、推荐信 2 封、研究计划（部分学校要求）
- **联系导师**：邮件模板 + 附件（成绩单、简历、代表作），大三下开始群发

## 考研

### 关键节点

| 时间 | 动作 |
|---|---|
| 大三上 | 定学校、定专业、定方向 |
| 大三下 | 数学/英语基础 |
| 大三暑假 | 数学强化 + 专业课第一轮 |
| 大四上 9 月 | 大纲发布，冲刺 |
| 大四上 12 月 | 初试 |
| 次年 2-3 月 | 出分、复试 |
| 次年 4 月 | 拟录取 |

### 常见坑

- **别拖到大四才开始**：数学/专业课需要至少 6-8 个月扎实周期
- **信息差最致命**：目标院校近 5 年真题、复试比、"歧视"传闻先摸清
- **备一个 B 计划**：调剂 / 二战 / 就业 → 心态更稳

## 留学

### 关键节点（以英美申请为例）

| 时间 | 动作 |
|---|---|
| 大二 | 语言（托福/雅思）+ GRE/GMAT 开始 |
| 大三上 | 定校（冲/主/保各 3-5 所）、联系推荐人 |
| 大三下 - 暑假 | 语言分数、科研 / 实习丰富履历 |
| 大四上 9-12 月 | 网申 |
| 次年 1-4 月 | Offer + 面试 |
| 次年 5-8 月 | 签证、行前 |

### 材料

- 成绩单（中英）+ WES 认证（部分学校）
- 语言（TOEFL/IELTS）+ 标化（GRE/GMAT）
- PS + CV + 2-3 封推荐信
- 作品集（艺术设计类）

## 输出

给用户一份「路径可行性对比 + 目标院校候选 + 12 个月里程碑」，落地到 `career_plan.md`。
